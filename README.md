ACHADOS & PERDIDOS — PROTÓTIPO INTERATIVO

1. Abra index.html no navegador para testar.
2. Para publicar na Vercel: acesse vercel.com/new, importe um repositório GitHub com estes arquivos (index.html, style.css, script.js) na raiz e clique Deploy. Também é possível usar a opção de implantação de projeto estático pela interface da Vercel, quando disponível.
3. Copie o endereço público HTTPS gerado e crie um QR Code apontando para ele.
4. Teste o endereço no celular usando internet móvel.

PÁGINAS: catálogo público, cadastro de objetos, consulta de registros, registro de saída e relatórios.

ATENÇÃO: projeto demonstrativo. Dados fictícios e armazenamento localStorage no navegador de cada visitante. O cadastro de uma pessoa NÃO aparece para outros visitantes. Não existe login real, autenticação, backend ou banco de dados. Não cadastre informações pessoais reais.

As telas foram inspiradas nos protótipos visuais do trabalho acadêmico. O design foi adaptado para dispositivos móveis.
